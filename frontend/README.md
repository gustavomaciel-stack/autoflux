# AutoFlux - Frontend

Frontend do MVP do AutoFlux em React e TypeScript.

## Executar localmente

1. Mantenha o XAMPP com Apache e MySQL ativos.
2. Importe o banco `autocar` no phpMyAdmin.
3. No terminal, entre na pasta `frontend`.
4. Execute `npm install`.
5. Execute `npm run dev`.
6. Abra `http://localhost:5173`.

A API utilizada por padrão é:

`http://localhost/autocar/api/routes/fornecedores.php`

Para alterar o endereço, copie `.env.example` para `.env` e ajuste a variável.
